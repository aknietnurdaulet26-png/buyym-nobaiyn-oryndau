# Нобай LAB

Казахская викторина «Бұйымның нобайын орындау»: до 22 учеников, 15 раундов, 66 вопросов.

## Включить GitHub Pages

Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save.

## Провести урок

1. Учитель открывает сайт на компьютере и нажимает **Бөлме ашу**.
2. Ученики открывают сайт на телефонах, вводят имя и шестизначный код. Можно отправить ссылку кнопкой **Сілтемені көшіру**.
3. После подключения учеников нажмите **Ойынды бастау**. Можно начать с меньшим числом участников.
4. Каждый раунд длится 45 секунд. Учитель может закончить его раньше, затем вручную запускает следующий.
5. Верный ответ: 100 баллов, максимум: 1500. Скорость не влияет на баллы. При равных баллах одинаковое место.
6. После 15-го раунда нажмите **Қорытындыны көрсету**. Сохраните результат кнопкой **CSV жүктеу**.

## Разные вопросы

Три уровня по 22 вопроса. Уровни чередуются: знание → применение → анализ. Каждый ученик получает пять вопросов каждого уровня. В одном раунде все 22 вопроса разные. Один ученик не получает один и тот же вопрос повторно. Равное количество вопросов каждого уровня не гарантирует абсолютно одинаковую сложность формулировок.

## Подключение и ограничения

Используются PeerJS 1.5.5, WebRTC и публичный PeerServer для соединения устройств. Firebase и регистрация не требуются. Учитель хранит ход игры в памяти своей вкладки. Не закрывайте и не обновляйте её, не допускайте сна компьютера: перезагрузка теряет комнату и результаты. Сохранение — через CSV.

Ученик может переподключиться через кнопку **Қайта қосылу** из той же вкладки, сохранив место и баллы. Новый браузер не восстановит прежнюю личность. После старта новые игроки не принимаются. Имена должны отличаться; можно добавить инициал.

Перед уроком проверьте подключение всех 22 реальных устройств в вашей сети. Тест алгоритма не является нагрузочным испытанием 22 телефонов. Публичный сервис и прямые WebRTC-соединения зависят от сети, NAT и брандмауэра. Выделенного TURN-сервера здесь нет. При проблемах попробуйте общую Wi-Fi сеть. Для ограничительных сетей нужна серверная архитектура, например отдельно настроенный Firebase. Документация PeerJS: https://peerjs.com/client/faq

Это учебная игра, не защищённая экзаменационная платформа: вопросы и ответы открыты в исходном коде. Имена и рейтинг видны участникам, поэтому используйте только имена или псевдонимы.

Внешние зависимости: cdn.jsdelivr.net (PeerJS), PeerServer Cloud (сигнализация), Google Fonts (необязательный шрифт). Микрофон и камера не нужны.

## Проверки

`node tests.cjs`

Проверяются 66 вопросов, все 22 участника и 15 раундов при разных смещениях, отсутствие повторов, распределение уровней, варианты ответов, равные места и CSV. Браузерная и сетевая проверка не заменяет проверку на устройствах класса.
